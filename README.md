# Teto Certo

Panorama do Investidor em Tempo Real: painel em Streamlit com Ibovespa, IFIX, dólar, euro, Selic, IPCA, alocação por perfil e radar de ações da B3.

Fontes: Yahoo Finance (yfinance), AwesomeAPI e Banco Central (SGS 432 e 433).

## Rodar localmente

```
pip install -r requirements.txt
streamlit run app.py
```
